# Demos

Recorded in a real Claude Code TUI against a **temporary local relay**; the
identity splash is anonymized. `.cast` files are asciinema recordings (replay
with `asciinema play <file>`); the GIFs are rendered with `agg`.

- **01-install** — loading the plugin; the agent lists its skills, with the
  inbox **monitor** active (`1 monitor`).
- **02-usage** — `init` → `send` → `receive`: an agent ("alice") sets up a user,
  messages a peer ("bob"), and receives bob's reply.
